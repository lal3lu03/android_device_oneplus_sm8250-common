# Android Device Tree - OnePlus SM8250 Common

This repository contains common Android device tree components for OnePlus SM8250-based custom ROM builds.

---

## Scope

This repository includes device-specific Android build configuration and integration work for the OnePlus 8 Pro, including:

* device tree maintenance
* LineageOS-based custom ROM support
* Qualcomm SM8250 platform integration
* vendor and hardware compatibility work
* build configuration updates
* device-specific debugging and fixes
